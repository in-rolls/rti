# Filing and follow-up

Use the shared [fieldwork viewer](https://in-rolls.github.io/rti/) to select your state, batch, and assistant ID. Check the application ID and exact office label before using an issued instrument. Preserve the assigned letter variant and version.

Record successful filings and failed attempts in the filing form. For a failure, record the reason; do not enter a filing date or registration number. For a successful filing, retain the portal's confirmation and record the actual filing date using `YYYY-MM-DD`.

Record each subsequent contact or document in the update form, including transfers, fee demands, replies, and appeals. Repeated events are separate observations. Keep evidence and original documents in the private study storage, not in this repository.

The public worklist shows assignments only. It is not an authoritative source for whether an office has responded. Contact the study coordinator before refiling an application or changing its assigned instrument.
